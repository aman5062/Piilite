Detect Aadhaar, PAN, GSTIN, UPI and other Indian PII in JavaScript

piilite detects every common Indian identity, tax, banking and contact format, checks real checksums, and understands how people in India actually write them.

How do I detect Aadhaar numbers in JavaScript?

Use new Piilite({ types: ["AADHAAR"] }) and call scan(). piilite accepts 12-digit numbers written plain, with spaces or with dashes, and keeps only those that pass the Verhoeff checksum UIDAI uses.

js
import { Piilite, aadhaar } from "piilite";

const s = new Piilite({ types: ["AADHAAR"] });
s.scan("Aadhaar: 4918 3726 5017");      // [{ type: "AADHAAR", value: "4918 3726 5017", ... }]
s.scan("UTR 412398765432 credited");    // [] (reference numbers are skipped)

aadhaar("491837265017");                // true: checksum only, no text needed

Numbers starting with 0 or 1 are never Aadhaar numbers. When the text says “aadhaar” (in English or eight Indian scripts), a number with a typo is still redacted, because the user clearly meant it as one.

How do I validate a PAN number?

A PAN is five letters, four digits and a letter, and its fourth letter must be a valid holder type (P for a person, C for a company, H, F, A, T, B, L, J, G). piilite checks both and skips codes after labels like SKU or model.

js
import { pan } from "piilite";
pan("ABCPS1234K"); // true
pan("ABCXS1234K"); // false: X is not a holder type

How does piilite check a GSTIN?

A GSTIN must start with a real state code (01 to 38, 97 or 99), contain a valid PAN, and end with the correct mod-36 check character. piilite verifies all three, so a mistyped GSTIN is not mistaken for a valid one.

js
import { gstin } from "piilite";
gstin("27AAPFU0939F1ZV"); // true

How do I detect UPI IDs?

piilite recognises UPI IDs on 85+ known handles such as @okhdfcbank, @ybl, @paytm and @oksbi. Any other name@handle counts when the text mentions UPI, GPay, PhonePe, Paytm or BHIM.

js
import { redact } from "piilite";
redact("pay rahul.k@okhdfcbank or 9123456780@ybl"); // "pay [UPI_ID_1] or [UPI_ID_2]"

Which Indian phone number formats are supported?

piilite detects Indian mobile numbers starting with 6-9 and landlines with STD codes, in every common format. It also understands digits in Indian scripts and numbers spoken in English or Hinglish.

How do I detect bank account numbers and IFSC codes?

Bank account numbers are 9 to 18 digits, so piilite only flags them after an account label (A/c, account, khata) or a bank name such as SBI or HDFC. IFSC codes are matched by their structure: four letters, a zero, and six characters.

js
redact("my SBI A/c 50100234567890, IFSC SBIN0004512");
// "my SBI A/c [BANK_ACCOUNT_1], IFSC [IFSC_1]"

How does piilite find Indian names?

piilite finds names from the words around them and from a dictionary of 1,100 first names and 640 surnames from every region, without an AI model.

  • Intros: my name is, mera naam … hai, myself, this is, and “my name is” in Hindi, Marathi, Bengali, Punjabi, Gujarati, Odia, Tamil, Telugu, Kannada and Malayalam.
  • Labels: Name:, Father's Name:, Candidate:, Beneficiary:, JSON keys like cust_name.
  • Titles and relations: Shri, Smt, Dr., Kumari, S/O, W/O, D/O.
  • Patterns: initials (K. Ramesh), surname endings (-kar, -wala, -iya), résumé header lines, CSV rows.

Places named after people (Gandhi Nagar, Nehru Place), schools (Vidya Mandir) and tools (MS Excel) are not flagged.

How does piilite find Indian addresses?

piilite finds addresses that start at a label (Address:, Ship to:, mera pata, ঠিকানা:), a house or village marker (Flat no, H.No, Vill., Post, Dist.) or a landmark (near, opp, Sector 15), and ends them at the PIN code.

js
redact("Address: Flat no 302, Sai Krupa Apartment, MG Road, Pune - 411001. Phone 9123456780");
// "Address: [ADDRESS_1]. Phone [PHONE_IN_1]"

Can piilite redact cities and locations?

Yes, with the opt-in LOCATION type. It is off by default because a city alone rarely identifies a person and search or matching features often need it.

js
new Piilite({ include: ["LOCATION"] }).redact("Based in: Kotputli, Rajasthan");
// "Based in: [LOCATION_1]"
