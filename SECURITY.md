# Security policy

## Supported versions

Security fixes go into the latest release on npm.

## Reporting a vulnerability

Please report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/aman5062/Piilite/security/advisories/new),
not in a public issue. Examples of security issues:

- input that makes a pattern run very slowly (ReDoS)
- a way to make `restore()` or the stream API leak a value that should stay redacted
- a crash on crafted input

A missed detection or a false alarm is not a security issue; open a normal issue for those (with fake data).

You can expect a first reply within 7 days.
